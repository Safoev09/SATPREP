# SATPrep — Update: Admin-Built Tests + Free/Premium Visibility

This update delivers the three changes you asked for.

## What's new

### 1. Free vs Premium per question
When you add or edit a question, the **Visibility** section now has a choice:
- 🆓 **Free for everyone** — any student can get this question
- ⭐ **Premium only** — only paid students get it

### 2. Build your own tests (admin)
New **"Tests"** section in the admin panel. You can now:
- Create a **single module** OR a **full SAT test** (4 modules)
- Give it a title, description, difficulty label
- Set it **free** or **premium**
- **Hand-pick questions** from your bank and order them (move up/down)
- For full tests, fill 4 slots: R&W Module 1, R&W Module 2, Math Module 1, Math Module 2
- Publish it when ready

### 3. Students pick which test to practise
- **Math modules / R&W modules** pages now show a **list of the module-tests you built**
- **Full mock test** page shows a **list of the full tests you built**
- Drills are unchanged — still auto-generated by skill
- Premium tests show a 🔒 to free users and send them to the upgrade page

## ⚠️ TWO install steps

### Step 1: Run the database migration

There's a new file **`migration-tests.sql`** in the project folder.

1. Open it, copy everything.
2. Supabase → SQL Editor → New query → paste → **Run**.
3. This adds the `visibility` column to questions, and creates the `tests` and `test_questions` tables.

### Step 2: Install the app code

1. Rename your Desktop `satprep-app` to `satprep-app-OLD-5`.
2. Extract `satprep-app-v6.zip` → open it → move the inner `satprep-app` folder to Desktop.
3. Confirm `.env.local` has your Supabase keys.
4. PowerShell:
   ```
   cd "C:\Users\safoe\OneDrive\Desktop\satprep-app"
   npm install
   npm run dev
   ```

## How to test

### Build a module test (admin)
1. Log in as admin → **Tests** → **Create test**.
2. Title it, choose **Single module**, pick a section.
3. In the question picker, click questions on the right to add them; reorder with ▲▼.
4. Check **Publish** → **Create test**.

### Build a full test (admin)
1. **Create test** → choose **Full SAT (4 modules)**.
2. Four slot tabs appear: RW Module 1, RW Module 2, Math Module 1, Math Module 2.
3. Click each tab and add questions to it.
4. Publish.

### Try it as a student
1. Log out, log in as student.
2. Sidebar → **Math modules** or **R&W modules** → you'll see your published module tests → click **Start**.
3. Sidebar → **Full mock test** → see your full tests → **Start**.
4. If a test is premium and the student is free, they get sent to the upgrade page.
