# SATPrep — Phase E Update: Review Queue, Progress, Profile

This update adds the last three core student features. **No SQL needed** — just install the app code.

## What's new

✅ **Review queue** (`/app/review`) — every question you tapped "Save for later" on, in one place. Expand each to see the passage, choices, answer, and explanation. Remove ones you've mastered.

✅ **Progress page** (`/app/progress`) — your full stats:
  - Overall accuracy, questions practised, sessions completed
  - **Score history** table (modules & full tests)
  - **Accuracy by skill** — colored bars, sorted weakest-first
  - A "suggested focus" callout pointing you to your weakest skill

✅ **Profile editing** (`/app/profile`) — students can now change their name, previous score, target score, region, and exam date. (Before, it was read-only.)

## Install (just the app code — no SQL this time)

1. Rename your Desktop `satprep-app` to `satprep-app-OLD-6`.
2. Extract `satprep-app-v7.zip` → open it → move the inner `satprep-app` folder to Desktop.
3. Confirm `.env.local` has your Supabase keys.
4. PowerShell:
   ```
   cd "C:\Users\safoe\OneDrive\Desktop\satprep-app"
   npm install
   npm run dev
   ```

## How to test

### Review queue
1. Do a drill, and tap **"Save for later"** on a couple of questions.
2. Sidebar → **Review queue** → your saved questions appear.
3. Expand one → click **Show answer & explanation**.
4. Try **Remove from review queue**.

### Progress
1. Complete a drill or two first (so there's data).
2. Sidebar → **Progress** → see accuracy stats, the skill bars, and score history.

### Profile
1. Sidebar → profile menu (top-right) → **Profile**.
2. Change your target score / exam date → **Save changes** → see the green "Saved".
